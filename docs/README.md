# 문서 목차

현재 사양은 설계·관리·운영 세 폴더에 있다. 제출산출물과 모델링 과제는 그때 제출한
그대로 둔 거라 지금 시스템과 다를 수 있다.

```
docs/
├── 설계/          지금 이 시스템이 어떻게 생겼는가
├── 관리/          무엇을 왜 만들고 언제 했는가
├── 운영/          어떻게 돌리고 고치는가
├── 제출산출물/     학교에 낸 것 (안 건드림)
├── 모델링/        DA# 과제 산출물 (엔터티 10개 기준)
└── diagrams/      ERD 이미지·원본
```

돌리면 CI가 막는다(`--check`).
