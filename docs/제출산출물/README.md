## 왜 안 지웠나

제출한 산출물은 그 시점에 뭘 계획했는지 보여주는 기록이다. 계획과 실제가 다른
부분(RDS+Lambda → EC2+Docker, 엔터티 12개 → 18개 같은)은 감출 게 아니라 왜
바뀌었는지 설명할 수 있는 재료라고 봤다.

바뀐 이유는 이쪽에 정리돼 있다.

- 아키텍처가 바뀐 이유: [../설계/설계_및_결정.md](../설계/설계_및_결정.md)
- 엔터티가 늘어난 이유: [../설계/ERD.md](../설계/ERD.md)
- 일정이 둘로 나뉜 경위: [../관리/WBS.md](../관리/WBS.md)
